# Portafolio rosa en movimiento

## Archivos
- `index.html`: estructura del sitio.
- `css/style.css`: colores, diseño responsivo, animaciones y formas.
- `js/script.js`: navegación, giro de la estrella, teclado y botón para copiar correo.
- `media/presentacion.mp4`: agrega aquí tu video de presentación.

## Personalización antes de entregar
1. Cambia `Tu nombre` y los textos de presentación.
2. Cambia `tu.correo@ejemplo.com` por tu correo profesional.
3. Reemplaza el enlace de LinkedIn por tu perfil real.
4. Actualiza las tarjetas de proyectos con tus proyectos, capturas, enlaces publicados y repositorios.
5. Añade tu video en `media/presentacion.mp4`.
6. Revisa el sitio en móvil y computador.

## Publicar en GitHub Pages
1. Crea un repositorio exclusivo en GitHub.
2. Sube todos los archivos manteniendo la estructura de carpetas.
3. En el repositorio entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y `/ (root)`, y guarda.
5. Espera a que GitHub Pages publique el sitio y abre la URL que entrega.

Este proyecto usa HTML, CSS y JavaScript sin frameworks ni dependencias de instalación.
